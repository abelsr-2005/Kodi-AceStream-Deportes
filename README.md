## 📖 Introducción

Este repositorio recoge una guía de instalación,
configuración y optimización de Kodi junto con Ace Stream
y complementos de terceros.

El objetivo es facilitar la configuración del sistema
desde cero, independientemente de los conocimientos
informáticos del usuario.

## 1. Requisitos previos

- Un dispositivo compatible con Kodi.
- Conexión estable a Internet.
- Espacio de almacenamiento disponible.
- Ace Stream compatible con el sistema operativo.

## 2. Instalación de Kodi

1. Accedemos a https://kodi.tv/download/
2. Seleccionamos nuestro sistema operativo.
3. Descargamos el instalador correspondiente.
4. Instalamos Kodi.
5. Iniciamos la aplicación.

## 3. Configuración inicial

### Cambiar el idioma a español

1. Accedemos a Ajustes.
2. Seleccionamos Interface.
3. Entramos en Regional.
4. Seleccionamos Language.
5. Elegimos Spanish.

## 4. Instalación de Ace Stream

Ace Stream es una tecnología de transmisión multimedia
que utiliza una arquitectura P2P.

1. Accedemos a https://www.acestream.org/
2. Seleccionamos la aplicación correspondiente.
3. Instalamos Ace Stream.
4. Comprobamos que el motor funciona correctamente.

## 5. Horus

Horus es un complemento de terceros que permite
integrar la reproducción de Ace Stream en Kodi.

La compatibilidad depende de la versión instalada,
del sistema operativo y del motor de Ace Stream.

## 6. Nada Que Ver

Complemento no oficial orientado al contenido deportivo
mediante tecnología Ace Stream.

Estado: pendiente de comprobar su funcionamiento,
procedencia y compatibilidad.

## 7. Optimización

Para mejorar la estabilidad de la reproducción:

- Utilizar una conexión Ethernet cuando sea posible.
- Evitar descargas simultáneas.
- Mantener Kodi actualizado.
- Comprobar el espacio de almacenamiento.
- Revisar los ajustes de caché.

## 8. Solución de errores

| Problema | Posible solución |
|---|---|
| Kodi no inicia | Revisar la instalación |
| Error de dependencias | Comprobar las versiones |
| Ace Stream no conecta | Revisar el motor y la red |
| Cortes de reproducción | Comprobar la conexión |
| Complemento no disponible | Revisar su mantenimiento |

## 9. Seguridad y privacidad

- Descargar aplicaciones desde fuentes fiables.
- No desactivar el antivirus.
- Revisar los permisos de los complementos.
- Mantener el sistema operativo actualizado.
- Tener en cuenta que P2P puede compartir datos
  y exponer la dirección IP a otros participantes.
